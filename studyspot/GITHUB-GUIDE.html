Upload StudySpot to GitHub

Two people: Remass and Wejdan. Both must push commits from their own GitHub accounts.

A. Remass: create the repository

1. Sign in at github.com, press + (top right) > New repository. Name it studyspot, choose Public, do not add a README, press Create repository.
2. Open a terminal inside the unzipped studyspot folder (VS Code: Terminal > New Terminal) and run: 
git init
git add .
git commit -m "Add StudySpot website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/studyspot.git
git push -u origin main
Replace YOUR-USERNAME. If Git asks you to sign in, use your GitHub login in the browser window, or a Personal Access Token as the password.

B. Add Wejdan as a collaborator

3. Repository > Settings > Collaborators > Add people. Type Wejdan's GitHub username and send the invite. She accepts it from her email or at github.com/notifications.

C. Invite the professor

4. Same page: Settings > Collaborators > Add people. Type ssbasabain@kau.edu.sa and choose Add (GitHub will offer to invite by email). The invite must be sent before the deadline.

D. Wejdan: commit from her own account

5. After accepting, Wejdan runs: 
git clone https://github.com/REMASS-USERNAME/studyspot.git
cd studyspot
She makes a real change (for example in about.html or css/style.css), then: 
git add .
git commit -m "Update About page"
git push
6. Remass pulls her work, and keeps adding small commits on different days: 
git pull
Use clear messages such as "Add reminders" or "Fix mobile layout". Commits only count on your contribution calendar if your Git email matches your GitHub account (git config user.email "your-github-email").

E. Publish the site (GitHub Pages)

7. Repository > Settings > Pages. Under Branch choose main and folder / (root), then Save.
8. Wait 1 to 2 minutes and refresh. GitHub shows the link https://YOUR-USERNAME.github.io/studyspot/. Open it to test, and put it in the report.

F. For the report

9. Take a screenshot of each member's contribution calendar (profile page, "contributions" graph). Screenshot the repository page and the Collaborators page showing the invite to ssbasabain@kau.edu.sa.
10. Name the report Group Number – CPIS358 – Section – Assignment1.docx and upload it to Blackboard with the website ZIP.

Do this before the deadline. Your site's favicon will appear on the GitHub Pages link even when it does not appear locally.
